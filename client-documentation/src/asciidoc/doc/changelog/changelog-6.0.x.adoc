
== Changelog for ecodex-connector-client-6.0.x

=== 6.0.1
==== Fixes
* global package distribution
* libraries package distribution
* images path in architecture documentation
* circular dependency between PDomibusConnectorClientConfirmation and PDomibusConnectorClientMessage models
* session ID clash when other application with same domain name and/or same context and/or same path are opened in the same browser (standalone version only) by
adding **server.servlet.session.cookie.name=CONNECTOR_CLIENT_J_SESSION_ID** to the properties file.

=== 6.0.0
==== Changes
* adds support for java 21.
* adds support for spring boot 3.x.x series
* update libraries to their latest version.
* adds a distribution module for a better application distribution.
* rename packages
